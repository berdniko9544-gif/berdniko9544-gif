### TKBK — один API-ключ к Claude, GPT, Grok, DeepSeek и GLM

Делаю **[TKBK (Tokens Bank)](https://tkbk.online)** — независимый API-шлюз для разработчиков: один ключ `cr_…` для Claude Code, Codex CLI, Cursor, n8n и любых SDK, форматы Anthropic и OpenAI, оплата в рублях по фактическим токенам.

| Репозиторий | Что внутри |

| [tkbk-api](https://github.com/berdniko9544-gif/tkbk-api) | быстрый старт: Claude Code, Codex CLI, OpenAI и Anthropic SDK, curl; модели и цены за 1M токенов |
| [tkbk-mcp](https://github.com/berdniko9544-gif/tkbk-mcp) | MCP-серверы для Wildberries, Ozon, Яндекс Маркета, Битрикс24 и amoCRM |
